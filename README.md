### About Me

대구소프트웨어마이스터고등학교에 재학 중인 **프론트엔드 개발자**입니다.  
사용자가 직접 마주하는 화면과 서비스의 흐름을 다듬는 과정에 큰 흥미를 느낍니다.

HTML, CSS, JavaScript를 기반으로 **React**와 **Figma**를 활용한 웹 개발 및 UI 설계 경험을 쌓고 있으며, 부전공인 **서버와 보안** 지식을 더해 서비스의 안정성까지 깊이 고민합니다.

화면 너머의 더 나은 사용자 경험을 디자인하는 개발자로 성장해 나가고 있습니다.
